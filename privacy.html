Privacy policy

1.1.0 · 2026-10-23

Version 1.1.0 · 23 October 2026. The current board, tool inventories, settings and reward identifiers remain on your device. Optional iCloud sync stores completed-level IDs and hint-demo records in Apple’s private CloudKit database; it does not sync the current board or tools. Manage sync in Settings; turning it off does not delete an existing cloud copy. Use Apple’s iCloud storage controls to manage cloud data. Local recovery copies may be retained during merging. There is no separate game account or developer-operated game server. If notification permission is granted, a local return reminder is scheduled 48 hours after the latest saved play; returning cancels it. Permission can be managed in system settings. The coin rules below apply only to version 1.0.1; version 1.1.0 uses tool inventories and includes both interstitial and optional rewarded ads. The provider, data-processing and rights disclosures below continue to apply.

No interstitials appear in the first 20 levels. After that, each 10 newly cleared levels can trigger one when you choose the next level, subject to a minimum 180-second full-screen-ad cooldown and ad availability. Replayed levels do not count. Optional rewarded videos grant one selected tool after reward confirmation; failed or early-closed ads grant nothing.
